# Lemmas used for the false-conjecture consistency check on this corpus.
# See eval/corpora/stdlib-regression/consistency-lemmas.txt for why the check
# runs against a curated list rather than every goal in the corpus.
#
# Produced by curating the generated ATP problems: each conjecture was
# replaced with $false and both E prover and Vampire were run at a longer
# timeout (10s) than the 2s check, so a lemma whose refutation is merely slow
# cannot pass here and fire during a run.  Only lemmas both provers left
# unrefuted are listed; a vacuously true lemma (contradictory hypotheses) is
# refutable however faithful the translation is and is excluded.
#
# Candidates were one lemma per generated module (a broad sample across
# the stdlib slice's MSets/Sorting/Structures/Logic modules), matching the
# stdlib-regression list's "broad sample" rationale rather than listing
# every goal.
#
# Curated against the knn-32 problems.  Vacuity depends on a goal's own
# hypotheses, not on which premises were selected, so one premise directory
# covers them all; a refutation appearing at a larger premise count during
# the check is a real finding about the translation rather than a gap here.
#
# Curation verdicts (original knn-32 curation): 143 kept, 5 refutable-from-axioms.
# The 5 were the Proper/complement Curry paradox (IsStrOrder.lt_compat,
# Raw2SetsOn.lt_compat, Update_OT.compare_spec, and two slower setoid/classical
# refutations WeakFanTheorem and ForallOrdPairs_inclA): unguarded definitional
# axioms for Proper (a diagonal, `Proper R m := R m m`) and complement (negation)
# let the untyped happ encoding self-apply to $false.
#
# Root cause and fix: those definitions only reached the prover because the
# `filter_classes` premise filter regressed to a no-op after the Stdlib->Corelib
# split (its prefix no longer matched Corelib.Classes.*); the same regression let
# the Hurkens universe-paradox lemmas leak via `filter_hurkens`.  With the filters
# corrected (src/plugin/features.ml), Proper/complement and the Hurkens lemmas are
# no longer selected, and all five formerly-refutable lemmas are consistent again
# -- verified by regenerating the whole corpus (17430 problems, 0 inconsistent).
# They are therefore REINSTATED below and now serve as a canary for the fix.
# See $PROJ notes/inconsistency.md and artifacts/extraction-confirmation/README.md.
#
# One fully qualified lemma name per line; blank lines and # comments ignored.
# Names must match the generated problem file names without the .p suffix.
