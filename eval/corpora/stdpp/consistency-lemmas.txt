# Lemmas used for the false-conjecture consistency check on this corpus.
# See eval/corpora/stdlib-regression/consistency-lemmas.txt for why the check
# runs against a curated list rather than every goal in the corpus.
#
# Produced by curating the generated ATP problems: each conjecture was
# replaced with $false and both E prover and Vampire were run at a longer
# timeout (10s) than the 2s check, so a lemma whose refutation is merely slow
# cannot pass here and fire during a run.  Only lemmas both provers left
# unrefuted are listed; a vacuously true lemma (contradictory hypotheses) is
# refutable however faithful the translation is and is excluded.
#
# Candidates were up to two lemmas per generated module, a broad sample
# across the std++ modules rather than every goal.
#
# Curated against the knn-32 problems.  Vacuity depends on a goal's own
# hypotheses, not on which premises were selected, so one premise directory
# covers them all; a refutation appearing at a larger premise count during
# the check is a real finding about the translation rather than a gap here.
#
# Curation verdicts: 89 kept, 0 refutable-from-axioms, 0 no-result.
#
# One fully qualified lemma name per line; blank lines and # comments ignored.
# Names must match the generated problem file names without the .p suffix.
