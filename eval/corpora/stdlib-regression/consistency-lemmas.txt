# Lemmas used for the false-conjecture consistency check on this corpus.
#
# The check replaces each conjecture with $false and expects the remaining
# axioms to be unrefutable.  Those axioms include the goal's own hypotheses,
# so a lemma with contradictory hypotheses is refutable for reasons that have
# nothing to do with the translation.  Stdlib has such lemmas: PeanoNat's
#
#   Lemma testbit_neg_r a n (H:n<0) : testbit a n = false.
#   Proof. inversion H. Qed.
#
# is vacuously true for nat and exists only to implement the NZBitsSpec
# interface shared with Z and N.  Checking it proves False from n < 0, which
# is correct translation of a correct Coq proof.
#
# So the check runs against this curated list of lemmas whose hypotheses are
# known to be satisfiable, rather than against every goal in the corpus.  The
# list does not need to be large -- it exists to catch a translation that
# makes consistent premises inconsistent, and a broad sample across the
# corpus modules does that.  Every entry below was verified to yield no
# refutation from its axioms alone.
#
# One fully qualified lemma name per line; blank lines and # comments ignored.
# Names must match the generated problem file names without the .p suffix.
